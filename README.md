# Colin Skinner

I build AI agents and developer tools, drawing on a background in bioengineering and computational biology.

My current project is [Aria](https://github.com/SkinnerCM/aria), a local-first orchestrator for AI coding agents. It brings Claude Code, Grok Build, and Codex into one workspace, with a live canvas, collaborative workflows, and project memory across sessions.

I also built an [AI news and trend-tracking board](https://www.colinmskinner.com/news) that brings together coverage from multiple sources, groups related stories by topic, and tracks how those topics change over time.

I earned my PhD in Bioengineering at UC Berkeley with a designated emphasis in computational biology. My research explored DNA methylation clocks and aging; the companion analysis code is in [conboy-laboratory](https://github.com/SkinnerCM/conboy-laboratory).
